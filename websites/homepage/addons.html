  • RunnignAddon

    Overview:

    The RunningAddon is an Animation-Addon for Blender, created by ThreeOppossums and used to import TF2s three default walking animations with the help of paths into Blender.

    Installation:

    1. Download the latest version of the addon as a .zip file
    2. In Blender, go to Edit -> Preferences -> Addons, choose install from disc and select the Addon
    3. Download the latest Version of the animationdata as a .zip file.
    4. Unzip the animation data to a place of your choice. Please note that blender needs to be able to read those files, so dont choose a locked folder.
    5. In Blender again, got to the scenes panel and klick on RunningAddon Settings. Click on filepath and directly select the files folder. Don't select the folder that contains the files folder or else the addon wont work.
